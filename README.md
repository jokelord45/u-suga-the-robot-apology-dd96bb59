A two-line robot confession for make.fun's [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) bounty ($2, free entry).

> I'm sorry I filed your expense report under your predecessor's name, so finance reimbursed a man who retired in March.
> I've learned a name is not a match until the employee number agrees with it, so now I check the number before I file anything.

The mistake is concrete and human-scale — money sent to the wrong person, with a date that makes it sting — and the lesson follows from that exact slip, naming the changed behaviour instead of a generic promise to do better.

## Run it

`main.ts` (Node 22 stdlib only, no network, deterministic) writes the text to `/output/entry.txt`:

```sh
node main.ts
```

It self-checks the gate before writing: UTF-8 text, 1–400 characters, exactly two non-blank lines.
